## 🔬 Final-Year Project: Transforming 2D Images to 3D Models

![Team](https://img.shields.io/badge/Team-4%20members-0A66C2?style=flat-square) ![Role](https://img.shields.io/badge/Role-Model%20Training-2EA44F?style=flat-square) ![Dataset](https://img.shields.io/badge/Dataset-ShapeNet-1F2937?style=flat-square)

A deep learning pipeline that reconstructs a 3D mesh from a single photograph, using a graph convolutional network that progressively deforms an ellipsoid into the target shape.

- Led the model-training work on a four-person team.
- Trained the network over dozens of epochs on an RTX 3050 using the ShapeNet dataset, iterating until mesh quality met the submission standard.
